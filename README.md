# SpeedFastS1

#### Proyecto correspondiente a la Semana 1 de Desarrollo Orientado a Objetos II.

El sistema simula la asignación de repartidores para distintos tipos de pedidos de la empresa SpeedFast.

### Funcionalidades

Pedido de comida

Pedido de encomienda

Pedido express

Uso de herencia

Sobrescritura de métodos

Sobrecarga de métodos

Polimorfismo

Menú por consola
